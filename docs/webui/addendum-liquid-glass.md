# 补充附件：Liquid Glass 材质引入规范

> 给实现方（LLM）：本文件是对《Agent 桌面客户端 UI 规格说明》（下称"主 spec"）和《UI 克制守则》（下称"守则"）的**增补与局部修订**。
>
> **优先级：本补充附件 > 守则 > 主 spec。** 仅在下文"第 1 节"列出的条目上覆盖前两份文档，其余一律照旧，尤其是守则中的克制原则依然完全有效。

---

## 1. 对原文档的修订（覆盖清单）

| 原文档条目 | 原规定 | 现在改为 |
|---|---|---|
| 主 spec 7.2 第 7 条 | 不使用大面积 `backdrop-filter`，不做大范围阴影动画 | **大面积仍禁止**。仅允许在本文第 3 节列出的少数元素上使用玻璃材质 |
| 守则 2.4「禁止发光、毛玻璃、彩色大阴影」 | 毛玻璃一律禁止 | **毛玻璃仅限本文第 3 节白名单元素**；发光、彩色阴影、渐变依然禁止 |
| 守则 2.3「禁止鼠标跟随发光、卡片 3D 倾斜」 | 全禁 | **依然全禁**。玻璃库自带的"鼠标跟随/高光跟随"必须关闭（见第 6 节） |
| 守则第三节动画白名单 | 仅列出的动画允许 | **新增两条**：① 玻璃元素的按压反馈（见 6.2）；② 标签页选中玻璃块的平移（已在白名单，沿用） |
| 主 spec 1.1「白色背景为主」 | 白底 | **保持白底不变**。玻璃是叠在白底与内容之上的材质，不改变整体背景色 |

## 2. 设计意图

- 目标不是"整个界面变成玻璃"，而是**只在少数悬浮层上使用玻璃材质**，让界面在白底之上有一点层次和通透感。
- 玻璃的价值来自"背后有内容"：折射和模糊只有在背后有东西时才看得见。**纯白背景上的玻璃几乎不可见**，所以必须按第 4 节调整布局，让内容能从玻璃后面经过。
- 整体仍遵守守则：克制、安静、无装饰。玻璃只是材质，不是装饰品。

---

## 3. 适用范围（白名单 / 禁区）

### 3.1 允许使用玻璃的元素

分两档，**档位决定用哪种实现**：

**A 档：真折射（较重，仅限小面积、静态或低频变化的元素）**
- 标签栏中"选中标签"的滑动背景块
- 「回到底部」浮动按钮

**B 档：纯 CSS 磨砂材质（较轻，可用于中等面积）**
- 顶部标签栏整体背景
- 输入框整体（含其上方 Todo 面板的容器）
- 弹出菜单、下拉、tooltip、权限确认卡片的浮层

### 3.2 禁止使用玻璃的地方（硬性）
- 消息内容本身（用户消息气泡、助手文本、代码块、表格、工具块、思考块）
- 消息列表的背景或任何大面积区域
- 玻璃叠玻璃（一个玻璃元素内部不得再嵌套玻璃元素；相互重叠时只保留最上层的玻璃）
- 任何持续动画的元素
- 任何需要频繁重排、随流式内容不断变化尺寸的元素（会导致折射每帧重算）

### 3.3 数量预算
- **同屏 A 档元素 ≤ 2 个，A+B 档合计 ≤ 4 个。**
- 超出预算时，优先降级 B 档（改为纯色实底），不要牺牲流畅度。

---

## 4. 布局调整（让玻璃有东西可折射）

为了让玻璃产生效果，需要对主 spec 第 1.2 节的布局做如下调整：

- 消息列表的滚动区域**延伸到标签栏下方和输入框下方**（即消息内容可以滚动到这两个玻璃层的后面被看到）
- 消息列表顶部和底部加对应高度的 padding，保证**静止状态下**最新消息和第一条消息不被玻璃遮挡
- 玻璃层的 `z-index` 高于消息列表，低于弹出菜单
- 滚动到边缘时，内容从玻璃后穿过应自然，不出现硬切边

> 提醒：这个调整会让内容长期在玻璃后面滚动，是全站最主要的"玻璃可见场景"，请重点验证性能。

---

## 5. 视觉规范（Design Tokens）

在 tokens 文件中新增以下变量，**玻璃相关样式一律走变量，禁止在组件里写死数值**：

```css
:root {
  /* 材质：白底之上的玻璃，偏白偏淡，不发灰 */
  --glass-bg: rgba(255, 255, 255, 0.62);
  --glass-bg-strong: rgba(255, 255, 255, 0.78);   /* 输入框等需要更高可读性的 */
  --glass-border: rgba(0, 0, 0, 0.06);            /* 1px 细边 */
  --glass-highlight: rgba(255, 255, 255, 0.7);    /* 顶部内高光，1px inset */
  --glass-blur: 18px;                              /* B 档模糊半径 */
  --glass-saturate: 1.15;
  --glass-shadow: 0 4px 16px rgba(0, 0, 0, 0.06); /* 仅这一档阴影，极淡 */

  /* 圆角沿用全站三档，不新增 */
}
```

- 玻璃元素的圆角**必须使用全站已有的三档圆角变量**，不得新增第四档
- 玻璃上的文字用主文字色，**不使用白色文字**；对比度必须满足可读性（正文文字与其背景对比度 ≥ 4.5:1），做不到就提高 `--glass-bg` 的不透明度
- **禁止**：彩色玻璃着色、渐变边框、发光边缘、彩虹色散（色散强度设为 0 或极低）
- 每个玻璃元素最多使用"细边框 + 内高光 + 极淡阴影"中的两项，遵守守则"三件套禁令"

## 6. 实现要求

### 6.1 必须使用现成库，禁止手写
- **禁止自行手写 SVG 位移滤镜、位移贴图或折射着色器。**
- A 档优先评估 `liquid-glass-react`（真折射，支持折射模式与弹性）；备选 `@liquidglass/react`
- B 档优先评估 `react-liquid`（纯 CSS 磨砂材质，提供卡片、按钮、输入框、标签页、浮层等组件）；若其组件不合适，可仅用其思路，在统一的 `GlassSurface` 中以 `backdrop-filter: blur() saturate()` 配合第 5 节变量实现
- **不使用 `@callstack/liquid-glass`**（那是 React Native 的 iOS 原生库，不适用于 Electron）
- 安装任何库之前必须先核实：最近维护时间、最新版本、许可证、是否兼容当前 React 和 Vite 版本、包体积。**核实结果写进交付说明。**
- 库都不合适时，**停下来告诉用户并说明原因，不要自己手搓 A 档效果**

### 6.2 统一封装
- 所有玻璃元素统一通过一个 `GlassSurface` 组件使用，业务组件**不得**直接引用第三方玻璃库
- `GlassSurface` 至少提供：`tier: 'A' | 'B'`、`radius: 'sm' | 'md' | 'lg'`、`strength: 'normal' | 'strong'`、`interactive: boolean`
- 这样以后换库或整体关闭只需改这一处
- 全局提供一个开关（`glassEnabled`），关闭后所有玻璃元素降级为纯色实底

### 6.3 交互与动画
- 玻璃库自带的**鼠标跟随、光斑跟随、`mouseContainer` 类功能必须关闭**
- 弹性（elasticity）只用于**按下/松开的瞬时反馈**，强度调低，不得有持续晃动
- 玻璃元素本身不做进入/退出以外的动画；进入退出沿用守则白名单（淡入 + 位移 ≤ 6px）
- 标签选中玻璃块的移动沿用白名单（平移 200ms），移动期间**保持折射参数不变**，不做逐帧参数动画

---

## 7. 降级与兼容

以下任一条件满足时，`GlassSurface` 自动降级为**纯色实底**（`#FFFFFF` 或 `#F7F7F8`，保留细边框和圆角）：

- 系统开启"降低透明度"（`prefers-reduced-transparency: reduce`）
- 系统开启"增强对比度"（`prefers-contrast: more`）
- 全局 `glassEnabled = false`
- 性能保护触发（见第 8 节）
- `backdrop-filter` 不被支持

降级后界面布局、尺寸、圆角、文字对比度必须与玻璃态保持一致，不能出现跳动。

---

## 8. 性能保护

- 玻璃元素不得因流式输出而重渲染；`GlassSurface` 必须 `React.memo`，并设置 `contain: paint`、`will-change` 仅在必要时短暂启用
- A 档折射元素**尺寸固定**，尺寸变化会触发昂贵的重新计算；需要变尺寸的元素只能用 B 档
- 开发环境的 FPS 面板（主 spec 第 7.2 节）新增显示：当前同屏玻璃元素数量
- **自动降级机制**：连续一段时间（如 2 秒）内帧率低于屏幕刷新率的 80% 时，自动把 A 档降级为 B 档；仍不达标则全部降级为实底，并在开发面板给出提示（不向普通用户弹任何提示）
- 验证场景（必须实测并写进交付说明）：
  1. 流式输出长文的同时上下滚动，内容从标签栏和输入框玻璃后经过
  2. 快速切换/新建/关闭多个标签
  3. Todo 展开折叠的同时消息流式输出

- [ ] 消息可以从标签栏和输入框玻璃后面滚动经过，静止时不被遮挡
- [ ] 所有玻璃样式来自变量，圆角只用原有三档
- [ ] 业务组件里没有直接引用第三方玻璃库，全部通过 `GlassSurface`
- [ ] 没有手写的 SVG 滤镜/位移贴图
- [ ] 库自带的鼠标跟随/光斑跟随已关闭
